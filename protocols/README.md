# Protocol Tracks

This repository is organized by protocol-specific learning tracks.

## Available tracks

- `protocols/http/` - HTTP request/response and polling basics.
- `protocols/websocket/` - WebSocket internals, benchmarking, and from-scratch demos.

## Suggested order

1. Start with HTTP fundamentals (`protocols/http/`).
2. Move to WebSocket (`protocols/websocket/`) for bidirectional realtime communication.
